# Claude Limit Closer (v1.2.1)

> এই ফাইলটি প্রতিটি পরিবর্তনের সাথে সাথে আপডেট করতে হয় (নিয়ম: `NOTES.md`-এর একদম উপরে)।

## এটা কী করে
Chrome-এর অনেকগুলো প্রোফাইলে claude.ai লগইন করা আছে। এই টুল সেগুলো ১০টি করে খোলে,
থেমে থাকা চ্যাটে "Continue" চাপে, আর ফ্রি লিমিট শেষ হলে ওই প্রোফাইলের Chrome বন্ধ করে দেয়।
তারপর পরের ১০টি প্রোফাইল খোলে।

## ফাইল
- `extension/` — মানুষের মতো কাজ করে: View all চাপে, চ্যাট খোলে, Continue চাপে। লিমিটের মেসেজ দেখলে Chrome বন্ধ করে।
- `launcher.py` — প্রোফাইল খোলে, সময় ধরে, পরের ১০টি শুরু করে, সব লগ `launcher.log` ফাইলে লেখে।
- `NOTES.md` — Claude-এর জন্য বিস্তারিত নোট (ইংরেজিতে)।

## কীভাবে চালাবেন
1. আগের পুরনো `claude_background_continue` এক্সটেনশন সব প্রোফাইল থেকে মুছুন (নইলে দুইবার চাপ পড়ে)।
2. প্রতিটি প্রোফাইলে `chrome://extensions` → Developer mode চালু → Load unpacked → `extension` ফোল্ডার দিন।
3. সব Chrome বন্ধ করুন।
4. `launcher.py` চালান।

## প্রথমবার টেস্ট
`launcher.py`-তে `BATCH_SIZE = 10` এর জায়গায় `BATCH_SIZE = 2` লিখে চালান। শেষে `launcher.log` ফাইলটা Claude-কে দেখান।

## সেটিং (`launcher.py`-এর উপরে)
- `BATCH_SIZE` — একসাথে কতগুলো প্রোফাইল (এখন ১০)
- `WAIT_AFTER_CLICKS` — সব ক্লিক শেষ হলে কত সেকেন্ড পর Chrome বন্ধ (এখন ১০)
- `PROFILES` — ফাঁকা থাকলে সব প্রোফাইল; নির্দিষ্ট করতে যেমন `["Default", "Profile 1"]`

## সতর্কতা
পুরনো `Claude Background Continue` এক্সটেনশন থাকলে মেইন ট্যাবের পাশে নতুন ট্যাব খুলতে থাকে। `launcher.py` চালু হতেই `launcher.log`-এ লিখে দেয় কোন প্রোফাইলে সেটা এখনো আছে (বা নতুনটা নেই)। সেই প্রোফাইল থেকে পুরনোটা মুছুন।

## অবস্থা
আসল Chrome-এ এখনো টেস্ট হয়নি। লিমিটের লেখা শুধু ইংরেজিতে মেলানো হয়।
