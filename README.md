# chrome_manager

এখানে চারটি আলাদা টুল আছে, চারটি আলাদা ফোল্ডারে। একটা অন্যটার ওপর নির্ভর করে না: প্রতিটা সেকশন সম্পূর্ণ স্বাধীন, তাই দরকারি সব ফাইল নিজের ফোল্ডারেই থাকে (একই নামের ফাইল একাধিক সেকশনে থাকতে পারে, সেটা ইচ্ছাকৃত)।

> নিয়ম: প্রতিটি পরিবর্তনের সাথে এই ফাইল, ওই ফোল্ডারের `README.md` আর `NOTES.md` আপডেট করতে হয় (নিয়ম `NOTES.md`-এর একদম উপরে)।

## ১. Claude Limit Closer — ফোল্ডার `1-claude-limit-closer-with-extention/`
Chrome এক্সটেনশন + `launcher.py`। প্রোফাইল ১০টি করে খোলে, থেমে থাকা চ্যাটে "Continue" চাপে, ফ্রি লিমিট শেষ হলে ওই প্রোফাইল বন্ধ করে।
বিস্তারিত: [`1-claude-limit-closer-with-extention/README.md`](1-claude-limit-closer-with-extention/README.md)

## ২. Chrome Opener — ফোল্ডার `2-chrome-opener-with-py/`
Python টুল (`Chrome_Opener.py`)। প্রোফাইল একটা একটা করে খোলে, মেইন ট্যাবেই `claude.ai/chats`-এ গিয়ে চ্যাট দেখে, থেমে থাকা চ্যাটে "Continue" / "Try again" চাপে, লিমিট শেষ হলে রিসেটের সময়ে নিজে আবার ফিরে আসে। সাথে `Chrome_Opener_Shut_Down.py` (সব অ্যাপ বন্ধ করে পিসি শাট ডাউন)।
বিস্তারিত: [`2-chrome-opener-with-py/README.md`](2-chrome-opener-with-py/README.md)

## ৩. Only Chrome Opener — ফোল্ডার `3-only-chrome-opener/`
Python টুল (`Chrome_Opener.py`)। **শুধু** প্রোফাইল খোলে আর লিমিট ধরে; চ্যাটে ঢুকে কিছু চাপে না। শুরুতে একসাথে ১০টা প্রোফাইল ব্যাচে খোলে, খোলা জানালাগুলো বারবার স্ক্যান করে, ফ্রি লিমিটের মেসেজ দেখলে ওই প্রোফাইল বন্ধ করে, আর রিসেটের সময় হলে নিজে আবার খোলে। সাথে `Chrome_Opener_Close_All` (সব Chrome জানালা বন্ধ) আর `Chrome_Opener_Shut_Down.py` (Chrome বন্ধ করে পিসি শাট ডাউন)।
বিস্তারিত: [`3-only-chrome-opener/README.md`](3-only-chrome-opener/README.md)

## ৪. Chrome Opener সিম্পল (কিছু মনে রাখে না) — ফোল্ডার `4-chrome-opener-simple/`
Python টুল (`Chrome_Opener.py`)। সেকশন ২-এর মতোই প্রোফাইল একটা একটা করে খোলে, সব চ্যাট খুলে "Continue" / "Try again" চাপে, লিমিট দেখলে প্রোফাইল বন্ধ করে। তফাত: **কিছুই মনে রাখে না** (রিসেটের সময়, দেখা চ্যাট, কিছুই না), একবার সব প্রোফাইল ঘুরে থেমে যায়, আর প্রতিটা প্রোফাইলের সময়সীমা ৫ মিনিট। সাথে `Chrome_Opener_Shut_Down.py`।
বিস্তারিত: [`4-chrome-opener-simple/README.md`](4-chrome-opener-simple/README.md)
