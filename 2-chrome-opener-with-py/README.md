# Chrome Opener (v2.1.0)

> এই ফাইল প্রতিটি পরিবর্তনের সাথে আপডেট করতে হয় (নিয়ম: `../NOTES.md`-এর একদম উপরে)।

## এটা কী করে
Chrome-এর অনেকগুলো প্রোফাইলে claude.ai লগইন করা আছে। এই টুল:
1. প্রোফাইল **একটা একটা করে** খোলে, পেজ পুরো লোড হলে কাজ শুরু করে।
2. **মেইন ট্যাবেই** `claude.ai/chats`-এ যায় (নতুন ট্যাব খোলে না)।
3. প্রতিটি চ্যাট খুলে থেমে থাকা চ্যাটে "Continue" / "Try again" চাপে।
4. ফ্রি লিমিট শেষ হলে ওই প্রোফাইল বন্ধ করে, রিসেটের সময় লিখে রাখে, আর **সময় হলে নিজেই আবার ফিরে আসে**।
5. কাজ শেষ হলে নিজের খোলা জানালা বন্ধ করে পরেরটা খোলে (আপনার নিজের খোলা জানালা বন্ধ করে না)।
6. আপনি মাউস নাড়ালে বা কিবোর্ড চাপলে **থেমে যায়**; ৩ সেকেন্ড স্থির থাকলে আবার চলে।

## ফাইল
- `Chrome_Opener.py` — মূল টুল।
- `NOTES.md` — Claude-এর জন্য বিস্তারিত নোট (ইংরেজিতে); সবার জন্য নিয়ম `../NOTES.md`-এ।
- `Chrome_Opener_Shut_Down.py` — আলাদা: সব অ্যাপ স্বাভাবিকভাবে বন্ধ করে পিসি শাট ডাউন করে। মূল টুলের সাথে যুক্ত নয়।

## কীভাবে চালাবেন
1. একবার: `py -m pip install psutil uiautomation`
2. সব Chrome বন্ধ করুন।
3. `py Chrome_Opener.py`
4. চলার সময় Chrome জানালা নিজে বন্ধ করবেন না। থামাতে কালো জানালায় Ctrl+C।

## যে ফাইলগুলো টুল নিজে বানায় (একই ফোল্ডারে)
- `activity_log.txt` — কী হলো তার লগ।
- `profile_state.json` — কোন প্রোফাইলে কতদূর কাজ হয়েছে।
- `report.txt` — বাংলায় সারসংক্ষেপ, প্রতিটা রাউন্ডের শেষে।

**এই তিনটি ফাইল ব্যক্তিগত।** কোথাও আপলোড বা কমিট করবেন না। চ্যাটের লেখা লগে কপি হয়ে যেতে পারে।

## সেটিং (`Chrome_Opener.py`-এর উপরে)
- `AUTO_RESUME` — `True`: রিসেটের সময় নিজে ফিরে আসে। `False` করলে এক রাউন্ডেই শেষ।
- `USER_IDLE_RESUME_SECONDS` — মাউস থামার কত সেকেন্ড পর আবার চলবে (এখন ৩)।
- `CLOSE_WINDOW_WHEN_DONE` — কাজ শেষে জানালা বন্ধ (এখন `True`)।
